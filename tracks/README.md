# tracks/

Track definitions shared by the trainer (Python) and the app (TypeScript).
This directory is the single source of truth: neither half embeds track data.

**Status: empty stub (Slice 1).** Track A (the 440 m training track) and
Track B (generalization) are copied from
[apex-evolve](https://github.com/wjesseclements/apex-evolve) in Slice 2, and
the JSON format is documented here at the same time — closed centerline +
width, in the SPEC §3.3 coordinate frame (x right, y up, meters).
